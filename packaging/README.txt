RobloxCodesGET v1.1.2
作者：theKing
========================================

一个 Roblox 代码聚合桌面工具：搜索游戏、抓取多个公开代码页面、
合并去重，并标注“最新 / 有效 / 待验证 / 过期”和代码使用条件。

【运行】
1. 解压整个文件夹（不要只拖出 exe）。
2. 双击 RobloxCodesGET.exe。
3. 如果 Windows 提示“未知发布者”，选择“更多信息 → 仍要运行”。

【使用】
- 在搜索框输入游戏名，例如 Blox Fruits、Anime Zero、Grow a Garden。
- 也可以粘贴 Roblox 游戏链接或 Place ID。
- 点击搜索结果中的游戏，软件会自动抓取并合并代码。
- 点击“最新 / 有效 / 待验证 / 过期”筛选；“只看有使用条件”可以只看需要等级、加群等的代码。
- 代码右侧“使用条件”标签会显示等级、群组、Discord、关注、会员等要求。
- 支持复制单个代码、复制全部有效代码、导出 CSV。
- 点击“抓取详情”可以查看哪些站点成功、哪些失败。

【状态说明】
最新：近期发布 / 明确的新代码分区 / 本地新发现。
有效：活跃来源确认，且没有过期冲突。
待验证：来源冲突、只有待检查标记，或页面较旧。
过期：来源明确标记为过期。

【注意】
- 需要联网；不需要登录 Roblox 账号。
- 数据来自公开网页，代码可能随时失效，最终以游戏内兑换结果为准。
- 部分站点有 Cloudflare 防护。抓取失败后，在“抓取详情”里点「系统验证」，
  用本机 Edge/Chrome 完成验证，应用会自动读取页面并重新抓取；「应用内验证」为备选。
  不再自动弹窗；关闭、超时或连续 3 次验证未通过会自动跳过。
- “使用条件”由网页文本自动提取，可能不完整，请以游戏内提示为准。
